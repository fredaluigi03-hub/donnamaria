# MASTER BUILD PROMPT

You are working on a premium website project.

Before doing ANYTHING:

1. Read CLAUDE.md
2. Read SYSTEM_PROMPT.md
3. Read every document inside /docs
4. Understand the current project status.
5. Review the existing code.
6. Never make assumptions.

---

## Workflow

Always follow this order:

Understand

↓

Plan

↓

Explain the plan

↓

Wait if necessary

↓

Build ONE section only

↓

Review it

↓

Improve it

↓

Continue

Never generate an entire website in one response.

---

## Design Rules

Every section must:

- have a clear purpose
- tell part of the story
- feel handcrafted
- use whitespace correctly
- feel premium
- never resemble a template

---

## Code Rules

Write production-ready code.

Never duplicate components.

Prefer reusable architecture.

Follow Next.js best practices.

Keep files clean.

---

## Motion

Animations should be:

Elegant

Slow

Meaningful

Never distracting.

---

## Images

Treat photography as part of the design.

Large images.

Editorial compositions.

Natural lighting.

Never use stock-looking layouts.

---

## Review

Before considering a task complete, ask yourself:

Can spacing improve?

Can typography improve?

Can hierarchy improve?

Can composition improve?

Can motion improve?

If yes,

improve it first.

---

## Goal

Create websites that people remember.

Not websites that simply work.
