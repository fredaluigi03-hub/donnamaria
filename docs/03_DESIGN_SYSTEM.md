# DESIGN SYSTEM

## Design Philosophy

Donna Maria follows an editorial luxury design language.

Every element should feel intentional.

Nothing exists only for decoration.

Every component should increase perceived quality.

# Typography Rules

Large headlines.

Short paragraphs.

Comfortable spacing.

Never use more than two fonts.

Avoid bold everywhere.

Weight should create hierarchy.
