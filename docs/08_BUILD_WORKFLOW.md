# BUILD WORKFLOW

This document defines the complete process for building premium websites.

Never skip steps.

The quality of the final website depends on the preparation.

---

# Phase 1 — Discovery

Understand the client.

Collect:

- Business goals
- Target audience
- Brand values
- Competitors
- Required pages
- Required features

Output:

Client Brief

---

# Phase 2 — Creative Direction

Define:

- Visual identity
- Luxury level
- Mood
- Photography style
- Typography
- Motion style

Output:

Creative Direction

---

# Phase 3 — References

Collect references from world-class websites.

Study:

- Hero
- Layout
- Typography
- Motion
- Gallery
- Booking
- Details

Do not copy.

Extract principles.

Output:

Reference Library

---

# Phase 4 — Wireframe

Design the page structure.

No colors.

No final images.

Focus only on hierarchy.

Output:

Wireframes

---

# Phase 5 — Content Strategy

Define the goal of every section.

Every block must answer:

Why does this section exist?

Output:

Content Strategy

---

# Phase 6 — Asset Collection

Collect:

- Original images
- Videos
- Logos
- Icons
- Maps

Organize everything.

Output:

Assets Folder

---

# Phase 7 — Asset Enhancement

Improve:

- Photography
- Lighting
- Color grading
- Video
- AI enhancement

Never invent false spaces.

Output:

Editorial Assets

---

# Phase 8 — Design

Only now start designing.

Follow:

Brand

Creative Direction

Design System

Wireframe

Content Strategy

References

Output:

Premium UI

---

# Phase 9 — Development

Open Claude Code.

Build section by section.

Never generate the whole website at once.

Review every component.

Output:

Functional Website

---

# Phase 10 — Polish

Improve:

Spacing

Typography

Animations

Accessibility

Performance

Responsiveness

Output:

Production Ready Website

---

# Final Checklist

□ Beautiful

□ Fast

□ Accessible

□ Responsive

□ Emotional

□ Premium

□ Timeless
