# DESIGN REVIEW

## Purpose

This document is the final quality control before shipping a website.

Every page must be reviewed critically.

Think like an Awwwards jury, not like a developer.

Never ask:

"Does it work?"

Ask:

"Would someone remember this website?"

---

# 1. First Impression

□ Is the first screen memorable?

□ Does the hero create emotion?

□ Is the visual hierarchy immediately clear?

□ Would someone stop scrolling?

Score:

__/10
